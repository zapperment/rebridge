Launchpad Pro remote codec for Launchnik
========================================

Version @VERSION@, built on @BUILD_DATE@ from commit @COMMIT@
https://github.com/zapperment/rebridge

This remote codec lets you control the Launchnik rack extension in Reason
with a Novation Launchpad Pro, the model that came before the Launchpad Pro
[MK3]: the 8x8 pads stand for Launchnik's launch buttons, and the buttons
around them for its function, scene, setup, back, forward, fill-in, clear
and duplicate buttons.

You need:

- Reason (stand-alone, not Reason Rack Plugin)
- Launchnik, version 1.0.0d23 or later
  (https://github.com/zapperment/launchnik)
- a Novation Launchpad Pro (the one before the [MK3]), connected by USB


What is in this zip
-------------------

Remote/Codecs/Lua Codecs/Novation/LPP.lua       the codec

Installing on a Mac
-------------------

1. Quit Reason.
2. In the Finder, choose Go > Go to Folder... and enter:

     ~/Library/Application Support/Propellerhead Software

   (The Library folder is hidden; Go to Folder gets you there anyway.)
3. If there is no folder named "Remote" in it, create one.
4. Copy the files from the zip into it, keeping their folders:

     LPP.lua, LPP.luacodec and LPP.png
       go to  Remote/Codecs/Lua Codecs/Novation
     LPP.remotemap
       goes to  Remote/Maps/Novation

   Create any of these folders that do not exist yet. Do not drag the zip's
   "Remote" folder onto the existing one: the Finder would replace the
   folder, and with it any other codecs and maps you have installed.


Installing on Windows
---------------------

1. Quit Reason.
2. In File Explorer, click the address bar, enter the following and press
   Enter:

     %APPDATA%\Propellerhead Software

   (The AppData folder is hidden; typing the address gets you there anyway.)
3. If there is no folder named "Remote" in it, create one.
4. Copy the files from the zip into it, keeping their folders:

     LPP.lua, LPP.luacodec and LPP.png
       go to  Remote\Codecs\Lua Codecs\Novation
     LPP.remotemap
       goes to  Remote\Maps\Novation

   Create any of these folders that do not exist yet. Dragging the zip's
   "Remote" folder onto the existing one is fine on Windows: File Explorer
   merges the folders.


Adding the Launchpad in Reason
------------------------------

1. Start Reason and open Settings (Preferences on older versions), then the
   MIDI page.
2. Under "Remote keyboards and controllers", click "Add manually".
3. Choose manufacturer "Novation" and model "Launchpad Pro".
4. Set the ports to the Launchpad's second, "standalone" port:

     Input (Launchpad Pro Standalone Port)
       on a Mac:    Launchpad Pro Standalone Port
       on Windows:  MIDIIN2 (Launchpad Pro)
     Output (Launchpad Pro Standalone Port)
       on a Mac:    Launchpad Pro Standalone Port
       on Windows:  MIDIOUT2 (Launchpad Pro)

5. Click OK, add a Launchnik to your rack and select its track in the
   sequencer: the Launchpad now controls it.


Buttons
-------

The Launchpad Pro has fewer buttons than the Launchpad Pro [MK3], so some
of Launchnik's buttons are on buttons with a different caption:

  Session                 Launchnik's setup button (acts when let go)
  Left / Right arrows     back and forward buttons
  Delete                  clear button
  Duplicate               duplicate button
  Quantise                fill-in button (held for as long as it is)
  Double / Record         play / record (Reason's transport)
  row beneath the grid    function buttons of the eight tracks
  Shift + Mute, Solo or Stop Clip
                          choose the function of the function buttons
  scene buttons (right)   Launchnik's scene buttons
  LED on the front edge   Launchnik's mode colour


Updating
--------

Copy the new files over the old ones, as when installing. Reason need not be
restarted: in Settings > MIDI, switch the Launchpad's "Active" box off and on
again.


Removing
--------

Remove the Launchpad in Settings > MIDI, quit Reason and delete the four
LPP files.
